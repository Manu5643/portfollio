# Sariki Gouri Manohar — Portfolio

## Run locally
1. Open this folder in VS Code.
2. Put your resume PDF at `assets/resume.pdf`.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload all files and folders.
3. Go to Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save. GitHub will provide your public portfolio URL.

## Important
Replace `assets/resume.pdf` with your actual resume file. The website currently uses only information supplied in the resume.
